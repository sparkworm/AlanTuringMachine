# AlanTuringMachine (ATM)

This is an educational project meant to act as a playground for Turing Machines.

## Functionality

The user may simulate a Turing machine of their own design and observe its 
behavior.

The machine may be simulated one step at a time, or take a set number of steps,
go until some condition is satisfied (state change, head over given tile.)
